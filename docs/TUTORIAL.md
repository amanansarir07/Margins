# Margins Tutorial

## 1. Choose a mission

Start with Solo mode, choose a destination, and read the objective and critical resources. Cadet mode adds hints while you learn.

## 2. Build the spacecraft

In the workshop, choose one item in each component tab. Watch the six resource bars after every choice:

- **Mass** must fit the spacecraft and launch vehicle.
- **Power** must cover the spacecraft's daily use.
- **Budget** pays for components, launch, orbit, and propellant.
- **Data** is the science data your instruments create.
- **Communications** is how much data can be sent home.
- **Time** covers transit and the selected orbit.

## 3. Review and launch

The Go/No-Go screen explains failed checks in plain English. Fix red checks before launching. A green check means the design fits that rule, not that every random event is harmless.

## 4. Learn from the debrief

The flight shows resource drain and events. The debrief explains the result and may suggest small, affordable changes. Use **Rerun with changes** or apply a suggested fix.

## Sandbox

Sandbox removes the budget and science-goal pressure. Use it to compare components and learn how trade-offs work; physical resource and launch checks still apply.
